01

공공기관

민원·예약·시설
  • “이번 주 민원을 유형별로 나누고 답변 초안까지 만들어 줘” → 조회·분류·근거 문단 찾기 → 담당자 검토 후 발송
  • “다음 달 공용 회의실 예약 현황이랑 빈 시간 정리해 줘” → 예약 조회·중복 확인 → 부서별 표
02

기업

재무·인사·IT
  • “이번 달 미수금 거래처 뽑아서 영업 담당에게 알려 줘” → 회계 조회·담당자 매칭 → 승인 후 발송
  • “신규 입사자 계정 만들고 장비 신청 넣어 줘” → 인사 정보 확인 → 승인 후 요청 실행
03

시설 운영

에너지·출입·혼잡도
  • “내일 오전 3층 회의실 냉방 미리 켜 줘” → 설정 범위 사전 검증 → 승인 후 예약
  • “지하 주차장 혼잡하면 방문객 안내 바꿔 줘” → 혼잡도 확인 → 승인 후 안내 변경
