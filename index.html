4계층 구조와 요청 하나가 처리되는 흐름을 확인해 보세요. 각 계층을 누르면 세부 구성이 열립니다.

EXAMPLE“내일 오전 3층 회의실 냉방 미리 켜 줘”

  1. 로봇 서비스배달·순찰·주차 로봇
    사용자 편의예약·출입 안내·검색과 결제
    에너지·환경 제어조명·냉난방·환기 자동 제어, 예측 정비
    공간 지능재실·혼잡도 분석, 이동 경로 최적화
    디지털 트윈공간·장비 실시간 매핑, 실행 전 사전 검증
  2. MCP서비스와 에이전트를 연결하는 표준 프로토콜

  3. A1로봇 조정
    A2사용자 지원
    A3에너지 최적화
    A4공간 지능
    A5공간·시설 AI 지능체
    A6통행·방문객 AI 지능체
    A7사건 처리 AI 지능체

    에이전트 간에는 A2A 프로토콜로 업무를 주고받습니다. A5~A7은 온톨로지와 직접 연동됩니다.

  4. 로컬 SLM → LLM 라우터일상 업무는 사내 소형 모델(SLM)이, 고난도 추론만 대형 모델(LLM)이 처리
    다중 모델 LLMGPT · Claude · Gemini · Llama 중 알맞은 모델
    RAGAS 품질 평가응답 품질을 자동 평가하고, 기준 미달 시 재학습
    메모리 · RAG대화 맥락, 의사결정 이력, 근거 문서 검색
    온톨로지 신경망공간·장비·인력·예약의 관계와 상태를 하나의 데이터 모델로 통합

  5. 현장 존재 여부혼잡도사용자 일정시간 구간장비 상태직원 정보온습도카메라·CCTV출입 정보
