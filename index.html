장애·데이터·보안·연동·PoC
01

장애가 나면 누가 대응하나요?

운영 단계에서는 carusworks가 1차 대응합니다. 장애 접수, 원인 분석, 복구, 재발 방지 보고 순서로 처리하며, 대응 채널과 응답 목표 시간은 계약 시 SLA로 확정합니다. 장애 중에는 AI 자동 실행을 멈추고 담당자 수동 운영으로 전환할 수 있도록 설계합니다.

02

데이터는 어디에 저장되나요?

사내 서버(온프레미스)가 기본입니다. 소형 모델과 메모리·검색 데이터를 고객 서버에 두고, 클라우드 모델로 보낼 업무의 범위는 고객이 정합니다. 폐쇄망 설치도 가능합니다.

03

보안과 권한은 어떻게 관리하나요?

에이전트마다 필요한 최소 권한과 호출 범위만 부여하고, 모든 호출을 이력으로 남깁니다. 인증 키는 고객이 보관하며, 계약이 끝나면 접근 권한을 회수합니다.

04

기존 시스템을 바꿔야 하나요?

아닙니다. 쓰고 계신 그룹웨어, ERP, 민원·예약·출입·설비 시스템을 교체 없이 연동하고, 에이전트는 MCP 표준으로 연결합니다.

05

작게 시작할 수 있나요?

네. 업무 하나와 데이터 하나로 PoC를 진행해 효과를 수치로 확인한 뒤, 적용 범위를 단계적으로 넓힙니다.
