## 변환 방법과 검증

- 붙임1~3은 바이너리 HWP(OLE2)입니다. pyhwp `hwp5html`로 변환한 뒤 마크다운으로 바꿨습니다. hwp5html이 하이퍼링크 필드 글자(이메일)를 빠뜨리는 문제가 있어서, 그런 문단은 `hwp5txt` 원문 줄로 바꿔 넣었습니다.
- 붙임4 규정 5개는 법제처 배포 HWPML(XML)입니다. XML을 직접 파싱했습니다.
- 표는 마크다운 표로 만들었고, 병합셀은 빈 칸으로 펼쳤습니다. 셀 하나짜리 상자는 인용 블록(`>`)으로 바꿨습니다.
