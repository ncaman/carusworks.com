Safe Execution

AI는 계획하고, 실행은 검증을 통과해야 합니다.

에이전트는 설비와 시스템을 바로 만지지 않습니다. 절차를 먼저 쓰고, 가상 환경에서 돌려 보고, 사람이 승인한 다음에 실행합니다.

01

절차 생성

지시를 받으면 실행할 절차 전체를 정해진 형식으로 먼저 씁니다.

02

가상 검증

디지털 트윈에서 먼저 돌려 보고 설정 범위와 안전 기준을 확인합니다.

03

사람 승인

담당자가 결과를 보고 승인합니다. 휴대폰에서도 됩니다.

04

실행·기록

승인된 절차만 실행되고, 모든 단계가 기록으로 남습니다.

가상 검증과 승인이 둘 다 없으면 시스템이 실행을 거부합니다.AI를 믿는 대신 코드가 막습니다.

Security & Governance

들일 수 있는 AI의 조건.

01

내부 서버 배포

온프레미스·폐쇄망
  • 내부 서버에 소형 모델·메모리·검색 데이터를 둡니다
  • 클라우드로 보낼 일은 고객이 정합니다
02

사람 승인

승인 없이는 실행 없음
  • 실행이 필요한 일은 담당자 승인을 거칩니다
  • 권고와 다른 결정에는 사유를 남깁니다
03

실행 기록

고칠 수 없는 기록
  • 계획·검증·승인·실행이 모두 기록됩니다
  • 같은 기록으로 다시 판정해 대조할 수 있습니다
04

품질 자동 평가

RAGAS
  • 응답 품질을 자동으로 잽니다
  • 낮아지면 검색 자료와 모델을 다시 학습합니다
05

모델 교체 가능

특정 업체에 묶이지 않음
  • 같은 틀 안에서 모델을 바꿔 끼웁니다
  • 숫자 계산과 판정은 모델이 아니라 코드가 합니다
