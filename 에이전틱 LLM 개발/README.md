> 개발일지(dev log)를 날짜순으로 쌓는다. 형도 여기 바로 커밋/코멘트 가능.

## 한 줄 방향 (2026-10-07 확정)
**모델은 안 만든다(오픈 코딩모델 받는다) + 우리가 만드는 건 "에이전트 하네스"(박씨 MCP 강점).**

## 폴더 규칙
- `NNN-제목-YYYY-MM-DD.md` 형식으로 개발일지 누적 (001부터)
- 결정/근거/비용/다음할일을 매 작업 시점마다 기록 (개발일지 원칙)
- 민감정보(키·토큰·개인정보)는 여기 적지 말 것 — 공개 레포임
