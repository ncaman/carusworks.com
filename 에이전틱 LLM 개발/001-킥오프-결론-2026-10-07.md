# 001 — 킥오프 결론: 코딩 에이전트 어떻게 만들 것인가 (2026-10-07)

## 결정
**"코딩 AI 만들기" = ① 모델(안 만듦, 오픈 받음) + ② 에이전트 하네스(이걸 만듦).**
- 사람들이 "Claude Code 똑똑하다"고 느끼는 건 모델보다 **하네스**(맥락관리·툴 오케스트레이션·반복루프). 모델은 오픈으로 이미 따라잡음 → **차이는 하네스에서 남 = 박씨 MCP 강점 영역.**

## ① 모델 — 안 만든다 (바닥학습 비용 때문)
| 방식 | 비용 | 판정 |
|---|---|---|
| 오픈모델 그대로 | $0 + GPU | ✅ 오늘 당장 |
| 파인튜닝(LoRA) | $40~$1,600/run(7B), ~$5,000 | ✅ 며칠(RVC 경험 재활용) |
| 바닥학습(소형) | $5만~$50만 | 🟡 |
| 70B급 바닥 | $100만~$600만 | ❌ |
| 딥시크/Claude급 바닥 | $2억+ | ❌ 불가 |

- 근거: DeepSeek-V3 최종 학습런만 **$557만**(R&D·인프라·실패런 제외). R1 추론 +$29.4만. → 전문회사가 수년+수백만$ 쓴 결과. 소규모 재현 불가.
- **결론: 바닥학습 금지. 오픈모델 받아서 도메인 LoRA 파인튜닝($수천불)으로 "우리 전용 모델" 명분까지 챙긴다.**

### 코딩 특화 최고 오픈모델 (2026.10)
- **DeepSeek V4-Pro** — SWE-Bench 80.6%, MIT, 온프레미스 MoE 원가우위 ★1순위
- **GLM-4.7** — HumanEval 94.2%, SWE-bench 73.8% (순수 코딩 최강)
- **Qwen3-Coder / Qwen 3.6** — Apache, 에이전틱 코딩·툴사용 최강
- **Kimi K2.6** — 자율 코딩에이전트(SWE-Bench Pro 58.6%)
→ 전부 Claude 근접, $0. 온프레미스/B2G면 DeepSeek V4.

## ② 에이전트 하네스 — 이걸 만든다 (오픈 프레임워크 위)
- 후보 프레임워크: **OpenHands**(구 OpenDevin) · **Aider**(딥시크공장장이 이미 사용) · **SWE-agent** · **Cline** · **Continue**
- 여기에 **박씨 MCP(파일·실행·배포 도구) + 도메인 파인튜닝** 얹음 = "우리 코딩 에이전트"
- 하네스는 돈이 아니라 **엔지니어링 시간**(오픈 위라 몇 주~몇 달). Claude Code급 신뢰성까진 반복 필요.

## 하드웨어(온프레미스 구동)
- 7~14B: RTX 4090(24GB) 1장(양자화)
- 32~70B: A100/H100(40~80GB) 1~2장
- DeepSeek V4(대형 MoE): 다GPU 서버(8×H100급) 또는 클라우드 렌트
- 학습(LoRA): Vast.ai GPU 렌트(박씨 RVC 경험)
